# Rag-version1

A project for implementing Retrieval-Augmented Generation (RAG).

## Features

- Retrieval of relevant documents
- Augmented generation using LLMs
- Modular and extensible design

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/HarithAiman243/Rag-version1.git
    cd Rag-version1
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Run the application:
    ```bash
    python main.py
    ```

## Project Structure

- `main.py` - Entry point
- `retriever/` - Document retrieval logic
- `generator/` - Text generation logic
